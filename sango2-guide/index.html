开打前必懂的五件事

停定打法（群雄基本功）

让敌人始终处于你的上方，你站在他偏下位置起手连技。是打牛金、夏侯渊、张辽、吕蒙、孙权、沙摩柯的核心手段，务必练熟。

属性相克

火属性 BOSS（黄盖、沙摩柯）怕冰系魔法 / 冰扇；吕布防御极高，必须穿蛮王藤甲（防冰、防电）再去打；程昱的木人怕火焰弹。

四神器 = 招降 & 通关钥匙

青龙 / 白虎 / 朱雀 / 玄武。第 7 关「再战金牌→真吕布」需要没打吕布且分数 ≥7000 万；招降曹操要「放任意 2 种神器 + 民兵策杀死」。

分数门槛一览

甘宁 3000 万 · 程昱 4500 万 · 周泰 5000 万 · 左慈扔「再战金牌」7000 万。撞击 BOSS 次数是拿高级武器的关键（撞曹操 5 下 = 倚天剑）。

AB 危险回避 & BC 道具

被围殴时用 AB 脱身；降将要用 Đối . 像神农古水 / 神龙古水（BC）把 BOSS 救醒再撞，是真方天画戟、张郃招降的前置。

火烧博望

魔王：夏侯惇招降：夏侯惇时限：天亮前撞击
◆ 关卡地图博望坡 / 地雷区 路线图　·　点图放大

路线要点

  1. 1开局两批小兵 → ↑ 进地雷区，再 → 前走。
  2. 2地雷区有 两批枪兵 + 一批刀兵：紧贴 ↑ 边或 ↓ 边沿走，千万别走中间。
  3. 3前进撞到铁甲步兵，撞一下得《太平道袍》。
  4. 4天亮之前撞击夏侯惇：1 下 = 神龙古水；3 下 = 青龙偃月刀（需关羽在场）。
  5. 590 秒后我军诈败退到 ← 地雷区，引爆地上炸药 → 招降或斩除。

夏侯惇 第一个 BOSS建议招降

不算难打，由下方切入连技即可。注意 R 模式的夏侯惇有很高几率挡格，出手要谨慎，建议直接完成地雷区引爆条件把他招降。

计袭新野

魔王：曹仁招降：曹仁4 处密室
◆ 关卡地图新野城 / 白河上游 路线图　·　点图放大

路线要点

  1. 1开局选择：连按 A = 放火，按 B = 不放火。
◆ 第一处分叉：放火 / 不放火

A 不放火

  1. ↑ 进武器库密室：一批炸弹兵 + 一批枪兵，清光。
  2. 按顺序打龙头 右2 左3 → 得道家密本。
  3. 接着 右1 左2 右3 → 得孙子兵法。
  4. 打开里面木箱 → 军令状。

B 放火

  1. 走屋顶路线：刀兵 + 炸弹兵，中途分三批出现老鹰。
  2. 击倒第一只老鹰 → 得血匕首（貂蝉在场）。
  3. 三打 / 四打中途可得锁子甲。
  4. 到屋顶尽头窟窿处 原地按跳 3 下 → 进屋顶密室。
  5. 清光炸弹兵，按 左2 右1 打龙嘴，龙嘴开后再打 右3 左2 右1 → 无军师得刀兵册，有军师得流马。
  6. 出密室可入手 巫刀（洞口原地跳 3 下，3 秒内击毁箭车）和 菲叶芸香（出密室处宝箱）。
◆ 第二处分叉：A 水淹白河 / B 追击白河上游

A 水路（推荐）

  1. 几批水兵，中途有饭团补血。
  2. 水兵之后打曹仁 → 死后可得水兵册、将军印、明光铠。
  3. 打破闸后曹仁未死的情况下，用招式打倒他 → 招降曹仁。

B 陆路

  1. 两批豹 → 两批豹 → 两批山贼。
  2. 在有 2 个破罐的树林间隙选路：↑ 森林密室A / ↓ 森林密室B。
  3. 密室A：杀两批山贼后开右上铁箱 → 祝融神火弓；左下木箱 → 刀兵册。
  4. 密室B：两个推箭车的机械兵，打破右面那辆车再撞击机械兵 → 黄袍（小心机械兵会走动）。
  5. 出密室迎战曹仁。

魔王打法

曹仁 贪分首选不会挡格

比夏侯惇更好打，上前直接连技（他不会挡格）。若第 1 关已招降夏侯惇，配合夏侯惇的破招能刷不少分。唯一注意 他身后的弓箭兵，连招途中别被射中断连。

血战长坂

魔王：张郃 / 司马懿 / 孟获招降：张郃3 处密室
◆ 关卡地图襄江 → 长坂坡 / 江夏 路线图　·　点图放大

路线要点

  1. 1开局一批难民逃跑，再走见第二批难民逃跑。先蹲下保护第二批中的老者 → 得民兵册 + 踏云天衣。
  2. 2保护难民建议用超必杀技（如火弓阵、长枪阵）清场。
  3. 3前进到路接近尽头处 ↑ 进难民密室：右下角宝箱 = 红缨梨花枪（小心工兵踢破箱子，最好用金珠射它）；右上角 = 七星灯（军师专用）；左上角 = 连环火甲车。
◆ 主线分叉：A 孤军深入长坂坡 / B 前往江夏求救兵

A 长坂坡

  1. 几台战车驶过（上下闪避）→ 4 个铁甲骑兵（超杀清）
  2. 两批铁甲步兵 → 之后的铁甲骑兵同上
  3. 数辆战车 → 建议用降将夏侯惇 / 曹仁全破
  4. 一批工兵阵：打第 1 批工兵阵型时马上撞击箭兵 → 出现 青缸剑
  5. 再分叉：→ 跳井（三宝箱：依次为火扇、古水、吴子兵法，另有反刃甲）/ ↑ 长坂坡密室（霸王战甲；用 B 跳击上空包袱三下得道家法典）
  6. 出来后三批阵型兵 → 见张郃

B 江夏

  1. 可保护刘琦（敌兵打他十下才死，紧贴 ↓ 路走即可；小心炸弹兵）
  2. 三部投石车，拆之 → 最上面那辆有饭团，还有军令状
  3. 几批小兵后见司马懿，中途有两棵菲叶芸香
  4. 司马懿死后得天师道袍、孙子兵法（三打以上还有神农古水）
  5. 长坂坡回程 → 三批阵型兵 → ↑ 长坂坡密室 → 出密室迎战张郃

魔王打法

司马懿 可无限连

18 人角色基本都能对他无限连：用招式把他打至高浮空，之后循环 66A → A → 66A → A…。实战一般只让张飞无限；赵云、孙权用 AAA·AAAA 打；貂蝉、关羽、庞统、马超、孔明、黄忠不建议（容易超时）。

张郃 存气五六格再打

常用两招：上天入地（闪过后连之）、扫荡群魔（等他耍完再上前连之）。打他之前身上一般有 4~5 格气，多放超必杀技即可。

孟获 沙包

只有走 A 长坂坡路线、和张郃交锋一段时间后才会出现。出现前后快速用超必杀搞定张郃，张郃死后孟获就是纯沙包（配合火牛踹地可拿丈八蛇矛）。

火烧连环

魔王：牛金 / 甘宁招降：牛金、甘宁3 处船舱密室
◆ 关卡地图曹魏船 / 东吴船 路线图　·　点图放大

路线要点

  1. 1开局 4 个铁甲骑兵 → 3 个水兵 → 前进再遇两批水兵（全杀之）。
  2. 2上船后选择：A 追击曹军，以立战功 / B 反击追兵，以绝后患。
◆ A 追击曹军（曹魏船）

→ 曹魏战船

  1. 直线一条路，都是水兵，中途可入手威灵仙。
  2. 再过几批水兵后到船尽头 → 迎战牛金。

↓ 曹魏船舱

  1. 干掉几个炸弹兵 → 一批铁甲步兵阵 + 一批刀兵阵 + 一批枪兵阵。
  2. 过之进曹魏船舱密室：从左到右 第 1、3、5 支蜡烛各打一下，消灭完所有敌人后站在倒数第 2 支蜡烛左面跳打两下。
  3. 密室内一群小动物，用火焰弹炸之得水兵册、刀兵册；中间木箱 = 道家密本；右上角铁箱 = 朱雀神器。
  4. 出船舱几批水兵 → 到船尽头战牛金（注意 进船舱就拿不到威灵仙）。
◆ B 反击追兵（东吴船：左 / 右）

左走 → 东吴船舱 A

  1. 一路水兵，中途得威灵仙；东吴战船尽头遇上甘宁。
  2. 中途 ↓ 进东吴船舱 A：几个小兵 → 一批铁甲步兵阵 → 两批兵阵 → 进东吴船舱密室。
  3. 密室（第 3、5 灯各打一下，最末灯在小兵清完后打两下）内含 盘龙三节棍、赤峰。

右走 → 东吴船舱 B

  1. 一路水兵，中途得人参；东吴战船尽头遇上甘宁。
  2. 中途 ↓ 进东吴船舱 B：几个小兵后进东吴船舱密室（不要打任何灯，等长枪兵睡醒即可）。
  3. 密室里有 盘龙三节棍、民兵册、于吉仙衣、七星灯。

魔王打法

牛金 新手大敌停定打法

开场在上面先毒气毒他一下再连技。核心是停定打法：尽量让牛金在你的上方，你站在他偏下位置连。
旁边会有小兵捣乱：长枪兵、刀兵用连技杀；机械兵直接扔莲花。他若挡格，你也跟着挡防 + 反击回避，逃跑再找机会。

甘宁 不怕晕·速度极快速杀有奖

连技 AAAA 的第四下会被强制中断，最好 AAA 三下接招式连。建议快速击败法：先对他用孙子兵法，再用兵书 + 长枪兵杀，别省能量，多放超必杀技。

魔王打法

徐晃 超 BT·出招硬直·挡格强

新手大敌。建议先用孙子兵法，再放道具书炸他，放长枪兵后接招。BT 归 BT，徐晃对各类攻击都受用，超必杀和道具尽管招呼。技巧 在他脚下扔铁莲花可全中 6 HITS。

夏侯渊 挡格超强停定

攻击常常被挡，建议用停定从下方切入连之。真正要小心的是南蛮兵、工兵、男弓蛮兵在后面捣乱；葫芦口场地窄，注意力多放在南蛮兵身上。

许褚 场地宽阔

北彝陵密室里的许褚不算难打，此处场地较宽，应多走动，诱他出「六丁开山」或「泰山压顶」（招式硬直时间长）进行连段。

张辽 道具流

会使各种道具招（小心他的枪兵和莲花）。同样用停定后从下方切入连之。R 模式注意 若第 1 关没招降夏侯惇，中途夏侯惇会来帮忙，最好集中先干掉一个。

程昱 召唤木人

道士类 BOSS，连技 AAAA 第四下会被强制中断，多用招式连。他常用真假分身术，应把他逼到右面角落打。
最恐怖的是会叫唤木人——全身硬直超 BT，但非常怕火，前面多准备火焰弹。

曹操 不会挡格

多用近身肉搏战术，用连技把他击倒后，在他身旁移动诱使「天断剑」，闪过连之。血量剩两条血时会不停使出「心是剑」——此时最好用超必杀技把他击倒，再诱天断剑，闪过连之，循环即可。

周泰 晕属性·挡格反击

大厅处的孙权不难打，场地较阔，多走动配合停定打法即可。

路线要点

  1. 1开局四个长枪兵 → 四个铁甲步兵。
  2. 2↑ 山寨密室（一开始往上方空洞处移动）：有个机械兵，用烟雾弹毒晕后撞一下得玄武神器（小心机械兵滚下山崖）。

◆ 火焰洞 / 油江竹筏 → 古墓

↑ 火焰洞 → 沙摩柯

  1. 上前击打墙上的石碑（没有男蛮兵那边的，记住石碑前面三下的闪动顺序）。
  2. 选 ↑ 火焰洞密室（打击没男蛮兵坐的石像）或 → 直走。
  3. 密室内干掉三批火牛后，按外面石碑闪动的顺序打（例：左右左，打左右左 ×3）打破铁箱 → 无军师得威灵仙，有军师得木牛。
  4. 出来几批火牛后 → 魔王沙摩柯出场 → 击败后 ↑ 进入古墓。

↓ 油江竹筏 → 古墓

  1. 一路上很多批水兵，通往竹筏尽头。
  2. 干掉几个驯兽师和几只老虎 → ↑ 进入古墓。
  3. 竹筏上其中一个水兵身上有水兵册，尽头工兵有神农古水。
  1. 5古墓：几条蛇和蝎子，干掉后可「引电」↓ 四神兽密室 或 → 前进。
  2. 6四神兽密室：四个桶怪，要在倒数 90 秒前干掉才能进第二层（建议超必杀），之后出来四个「左慈」。
    分辨真假左慈：① 对角法——左慈刚出来方向的对角（例：出来在右下，对角是左下）；② 用道家密本 / 道家法典把三个假的烧死。成功进入第二层，失败则回古墓迎战左慈。
  3. 7第二层：四个木人（同上），建议用火系魔法击倒。分辨真假左慈：① 斜角法（例：右下 → 斜角左上）；② 同上烧死假的。成功进入白虎密室战吕布，失败则回古墓迎战左慈。
  4. 8→ 前进路线：干掉几个桶怪（逐个引出，最后两个用超必杀或道具，两个金珠可杀死一个桶怪）→ 左慈出场。
  5. 9击败吕布 / 左慈都可来到大厅。干掉三只小熊 → 遇上双王 曹操 + 孙权。
    真吕布条件 若之前没打吕布且分数达 7000 万以上，左慈会飘过扔下「再战金牌」，入手金牌即可挑战真吕布。

魔王打法

孟优 骑大象半血后变沙包

对付方法很多：烟雾弹、降将、AB 危险回避技，最实用首选降将。走吴路用甘宁（236A 或 28A），走曹路用徐晃（A 或 236A）。
剩下半条血时大象会逃跑，那时孟优就是个沙包。注意 身旁的南蛮兵超 BT；若是孟优 + 孟获同场反而没有小兵，往往比单打更易。

沙摩柯 火属性不会挡格·最适停定

个人认为是最适合用停定的 BOSS——不会挡格，停定打他就像切豆腐，只需小心后面的火牛兵。相克 冰属性魔法与攻击克制沙摩柯。

吕布 防御超强必须穿蛮王藤甲

打他身上一定要有防冰和电的衣服，首选蛮王藤甲。连技 AAAA 第四下会被强制反击，最好 AAA + 招式 连之，尽量从下方切入。小心加耐心，击败他没问题。

左慈 卡桶怪引电

杀掉左慈出来时的第一个桶怪（那不是左慈放的）——只要是左慈手上放出的桶怪就可以卡。
例：你在左面，紧贴墙边上下移动且不按 A，桶怪就会一直停在右面不来，形成左右对峙局面。要卡桶怪在右面（卡在左边引不到电），之后慢慢引电来电击左慈即可。

曹操 + 孙权 双魔头联手

只能先干掉其中一个。两者以曹操难对付：剩两条血时（红血状态）会疯狂出「心是剑」。最后一关了别省资源——他放心是剑时用超必杀技（没气就喝古水），集中干掉曹操；剩下的孙权用停定慢慢打，沙包一个。

真吕布 全游戏最强攻高防高速度快·全属性免疫

准备：白虎神器 ×1、古水 1~2 瓶、徐晃 ×2 或 ×4，身穿蛮王藤甲。
开场套路：走动引他到下方，用超必杀击倒 → 真吕布倒在角落 → 立刻使用白虎神器（约 25 秒），然后按下面任一方案输出：

  • ① AAAA + 招式击倒 → 火弓阵 + 徐晃烧 8~9 下 → 再 AAAA + 招式击倒 → 火弓阵 + 徐晃再烧 8~9 下 → 喝水放超必杀（双赵云、双黄忠）
  • ② 长枪阵 + 徐晃（长枪阵中徐晃狂 A）；25 秒白虎可放 4 次 → 喝水超必杀（双赵云、张飞、双孙权）
  • ③ 滚石阵 + 徐晃（右→左时徐晃跟着石头跑）×3 轮 → 喝水超必杀（双马超、隐凤雏）
  • ④ 神将术 + 莲花 + 236A + A + 236A；白虎 25 秒中神将加莲花 ×4 → 喝水神将术 + 莲花 ×5（智孔明、庞统）
  • ⑤ AAAA + 236A ×4，白虎中可打一条多血 → 喝古水 ×2 → 28 ×10（双张飞）
  • ⑥ 徐晃 A + 28A 猛打一条多血 → 三瓶古水无限连直接 KO（孔明）
  • ⑦ 一直 28A；白虎过后在角落不停放 28A，可从头屈到死（双貂蝉，须配飞天虎爪）

通用循环（18 人皆适用）：用超必杀把真吕布放倒后，离远站在中间位置停住——近身他会出「霸气无双（指地成钢）」，离远则会出「黑熊穿云」（闪到背后抓下来）。等他出黑熊穿云后往下一拉闪过，上前连之，循环即可轻松通过。
若他放「风暴」这招：用 2B 蹲下 + A+B + AAAA + 招式 连之。
伤害参考 除⑥⑦可屈死外，其余五种每条命都能打掉两条到两条半血（真吕布共四条血）。
